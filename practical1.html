Introduction

Welcome to the Web Designing with HTML laboratory. HTML is the standard markup language used to create web pages. It is the first step in learning Frontend Web Development.

Course Outcomes

Students will learn:
• Basic structure of an HTML document.
• Different HTML tags used for designing web pages.
• How to display headings, paragraphs and special symbols.
