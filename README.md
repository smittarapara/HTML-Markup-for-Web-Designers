# 📖 About this Repository

This repository contains laboratory practicals, HTML programs, assignments, mini projects, and reference materials developed for the **HTML Markup for Web Designers (CIE1001C)** course.

The practicals provide hands-on experience in HTML5, CSS3, semantic web design, multimedia integration, tables, hyperlinks, forms, responsive layouts, and website development following modern web standards.

---

# 🎯 Course Outcomes

- Understand the fundamentals of web technologies and HTML document structure.
- Create structured and interactive web pages using HTML5 elements.
- Apply CSS properties to develop responsive and visually appealing webpages.
- Build interactive forms and publish websites using standard web development practices.

# 🧪 Practical List

| No. | Practical Title |
|:--:|-----------------|
| 1 | Create a basic HTML webpage using HTML, HEAD, TITLE, and BODY tags demonstrating headings, paragraphs, line breaks, horizontal rules, comments, and special character entities. |
| 2 | Create a webpage using ordered, unordered, description, and nested lists to represent structured content such as course modules or website menus. |
| 3 | Create a webpage using HTML5 semantic elements such as header, nav, section, article, aside, and footer with a consistent navigation structure. |
| 4 | Create a multi-page website using semantic elements and embed external content using iframe elements. |
| 5 | Create a personal profile webpage using text formatting tags such as b, i, u, strong, em, and mark. |
| 6 | Create a webpage using internal, external, email, and bookmark hyperlinks for navigation. |
| 7 | Create an image gallery webpage displaying images with appropriate attributes and hyperlinks. |
| 8 | Create a multimedia webpage integrating text, images, audio, and video elements with playback controls. |
| 9 | Create a timetable and product catalog using HTML tables including captions, headers, rowspan, colspan, and merged cells. |
| 10 | Apply CSS color, background, font, text, border, margin, padding, width, and height properties to enhance webpage appearance. |
| 11 | Create a webpage demonstrating the CSS Box Model, display properties, and positioning techniques. |
| 12 | Create student registration, login, feedback, and contact forms using HTML form controls. |
| 13 | Apply HTML5 input types and validation attributes such as required, pattern, min, max, minlength, and maxlength. |
| 14 | Develop advanced HTML5 forms using modern input controls and validation techniques. |
| 15 | Create a responsive multi-page website integrating semantic HTML, navigation menus, forms, multimedia, tables, hyperlinks, and CSS styling. |
